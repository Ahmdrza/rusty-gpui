# Changelog

## 0.4.0 — 2026-10-30

First published release.

- Native buttons, fields, selection, navigation, overlays and data components.
- Configurable themes, shared control styling, bundled fonts and icons.
- Single-window application helper and complete hello, form and overlay examples.
- Interactive development gallery with theme controls and virtualized tables.
- Maintained GPUI runtime and component forks with keyboard, focus and macOS activation fixes.

See [support and limitations](docs/support.md) before adopting this pre-1.0 release.
