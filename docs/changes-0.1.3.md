# Rusty GPUI 0.1.3

- Searchable selects use the same control height, vertical/horizontal padding and density category as Rusty GPUI text inputs. The reusable helper is rusty_gpui::select.
- Dropdown menus use their trigger’s measured width as a minimum, including full-width Project actions. Their width updates when the trigger resizes.
- Previous fixes are included.

Compile checked only. No GUI tests were run for this revision, as requested. Run bash scripts/run-macos.sh from the extracted form folder; the sidebar displays Rusty GPUI 0.1.3.
