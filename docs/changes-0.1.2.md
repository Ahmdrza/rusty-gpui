# Rusty GPUI 0.1.2

- Icon-only buttons omit empty labels and use equal width/height with zero text padding.
- The searchable select uses SearchableVec, so its query filters options.
- Modal and drawer backdrops share a black scrim at 42% opacity in both appearances.
- Colored action buttons use white text with contrast-adjusted fill colors. Light neutral buttons retain dark text. Loading buttons no longer fade both their fill and text.
- Includes the previous scrolling, live search, full-height drawer and disabled-field corrections.

Compile checked only, as requested. No GUI tests were run for this release; review the native app on your Mac. The included screenshots are earlier design references.

Run bash scripts/run-macos.sh from the extracted form folder. The sidebar displays Rusty GPUI 0.1.2.
